## 詩音について

詩音はあなたのデスクトップに住む小さな女の子です。まばたきしたり、呼吸したり、ぼーっとしたり、ときどき独り言を言ったりします。
Claude Code（または ChatGPT の Codex）で作業しているときは**そばで見守ってくれます**。作業が始まると真剣な顔になり、終わったら知らせてくれて、確認が必要なときは目の前まで持ってきてくれます。

コードを読んだり、ネットに接続したり、あなたの代わりに AI と会話したりはしません。ただ、そばにいてくれるだけです。

## 機能

### Claude Code との連動
- **状態の把握**：作業中・完了・エラー・確認待ちに合わせて表情が変わり、声をかけてくれます
- **許可リクエストへの応答**：Claude Code がコマンド実行やファイル編集を求めると、詩音が「許可 / 拒否」パネルを出します（Claude Code 側で答えても OK。先に答えた方が有効です。**勝手に許可することは絶対にありません**）
- **止める / 続ける**：次のツールのチェックポイントで止まり、頭上に「一時停止中」を表示。クリックで続行
- **今すぐ中断**：実行中のツールプロセスを止め、次のチェックポイントでターンを終了します。出力中の文章は、今の一文が終わるまで続くことがあります。作業プロセスが見つからない場合は、次のチェックポイントで一時停止します
- **よくできました / 問題あり……**：あなたの評価を作業中の AI にそっと伝えます（コンテキストとして追加されるだけで、会話にメッセージは増えません）
- **計画・完了のお知らせ**：見に行くよう知らせるだけで、内容はデスクトップに表示しません
- **複数セッションの同時作業**：Claude Code のセッションが複数動いているときは、「作業リモコン」の止める・今すぐ中断・よくできました・問題あり……がサブメニューになり、1 つのセッション（または「すべて」）を選べます。セッションはプロジェクトフォルダ名で区別し、同じプロジェクトで 2 つ開いているときは最初の発言の冒頭数文字も表示します
- **連携を一時停止**：右クリック →「AI 連携」→「Claude Code」→「連携を一時停止」。停止中はパネルを出さず、許可は Claude Code 側に任せます。いつでも再開できます
- **詩音が起動していなくても Claude Code が遅くならない**：hook は詩音がいないとすぐに Claude Code へ処理を返し、待ちません

### ChatGPT（Codex）の観測
- Codex CLI と Codex デスクトップアプリに対応：作業の開始、ツールの実行、許可待ち、完了に合わせて表情が変わり、声をかけてくれます
- **観測のみ**：Codex の許可・停止・中断を代わりに行うことはできません。確認が必要なときは、Codex 側を見に行くよう知らせるだけです
- Claude Code とは別に管理：右クリック →「AI 連携」→「ChatGPT」でインストール・一時停止・削除できます

### ふだんのふれあい
- なでなで（ハートが出ます）、つつく、ほっぺをつまむ、くすぐる、持ち上げて振る（目を回します）
- 「お話 → おやつをあげる」、または用意された会話を選んで少しおしゃべり（AI モデルは使いません）
- 「動作」メニュー：ジャンプ、ベッドで寝る、ちょっと伏せる
- 時間帯に合わせたあいさつ：朝は朝ごはんのこと、深夜は「早く寝て」
- **好感度**：なでなで・おやつ・会話で少しずつ上がり、5 段階のレベルで新しい会話・おやつ・セリフが解放されます
- 中文 / English / 日本語

### じゃまをしない
- 透明な部分はクリックが下のウィンドウに届きます
- パネルは**表示時にキーボードのフォーカスを取りません**。会話ウィンドウをクリックすると数字キーで選べ、フィードバック入力欄をクリックすると入力できます
- 「最前面に表示」はオフにできます。Claude デスクトップアプリや Codex デスクトップアプリのウィンドウが前面に戻ると、詩音はそのすぐ上に表示されます
- 吹き出しのミュート、「状態だけ表示（内容は隠す）」、4 段階のサイズ、活発さの調整

## 動作環境

- Windows 10 / 11（macOS / Linux は未対応）
- [Claude Code](https://docs.claude.com/en/docs/claude-code)（CLI 版、またはデスクトップアプリの Code）、または Codex（CLI 版、またはデスクトップアプリ）。どちらとも連携しなくても普通のマスコットとして使えます

## インストール

1. [Releases](../../releases) から `Shion-2.0.0-win64.zip` をダウンロード
2. **固定の場所**に展開します（例：`D:\Apps\Shion`）。あとで移動した場合は右クリック →「AI 連携」→「Claude Code」→「接続 / 設定を確認」で再接続してください
3. `Shion.exe` をダブルクリック
4. 初回起動時に Claude Code と接続するか聞かれるので、**接続** を押します

Python のインストールは不要です。

> [!TIP]
> 「Windows によって PC が保護されました」と表示されたら、**詳細情報 → 実行** を押してください。コード署名のないアプリでは、この警告が表示されることがあります。

## Claude Code との接続

「接続」を押すと、詩音の hooks が**ユーザー単位**の設定 `%USERPROFILE%\.claude\settings.json` に追加され、どのフォルダで Claude Code を開いても連動します。

- 変更前に元のファイルを自動でバックアップします（`settings.json.shion-backup-日時`）
- 追加・削除するのは詩音自身の項目だけで、ほかの設定はそのまま残ります
- 設定ファイルの形式がおかしい場合は書き込みを中止し、ファイルを壊しません
- いつでも **右クリック →「AI 連携」→「Claude Code」→「切断して設定を削除」** できます。少し止めたいだけなら「連携を一時停止」を選んでください
- 以前のソースプロジェクトに詩音のプロジェクト単位の hooks がある場合は、そこで `tools\uninstall_hooks.py` を実行してから exe で接続してください。exe では古いプロジェクトの hooks を移行できません

接続後に**新しく開いた** Claude Code のセッションから有効になります。

## ChatGPT（Codex）との接続

ChatGPT との連携は別にインストールします：右クリック →「AI 連携」→「ChatGPT」→「接続 / 設定を確認」。

- Codex の設定（既定では `%USERPROFILE%\.codex` の `config.toml` と `hooks.json`）への変更内容を先に表示し、確認してから書き込みます。追加するのは詩音自身の項目だけで、設定のコピーは保存しません。切断時は記録どおりにその項目だけを削除し、内容が変わっていて一致しない場合は上書きせずに止まります
- インストール後、Codex の `/hooks` で詩音の各 Hook を確認し、`/mcp` で接続を確認してください。初回は Codex を再起動してから、会話を新規作成または開き直してください
- 同じサブメニューから「連携を一時停止」「切断して設定を削除」ができます

## 使い方

| 操作 | 効果 |
|---|---|
| 左クリック | つつく |
| 頭の上で左ボタンを押したまま左右に動かす | なでなで |
| ほっぺを横に引っぱる | ほっぺをつまむ |
| おなかを 3 回クリック / 押したまま左右にこする | くすぐる |
| ドラッグ | 持ち上げる。離した場所にとどまります。強く振ると目を回します |
| ダブルクリック | 状態を表示（一緒にいる時間、好感度レベル、接続状態） |
| 右クリック | メニュー：ふれあい、作業リモコン、ペット（表情、動作、サイズなど）、AI 連携、設定（言語、スタートアップで起動）など |

## プライバシー

- すべてあなたの PC 内で完結します。ローカルサーバーは `127.0.0.1` だけで待ち受け、Web ページからのリクエストは拒否します
- **外部ネット接続なし・データ送信なし・AI モデルの呼び出しなし**。hooks の通信はローカルホスト内のみです
- 詩音は hooks のイベントを受け取り、許可パネルには操作の詳細を表示します。通常の作業表示は短い要約で、ファイル名などの詳細がローカルログに残ることがあります。コードファイルや会話本文は保存しません
- 「状態だけ表示（内容は隠す）」では作業の詳細を隠し、それ以降のイベントログにも詳細を含めません。既存ログは残ります。許可パネルには確認が必要な操作を引き続き表示します
- hook と詩音のあいだは一度きりのトークンで認証し（詩音を起動するたびに新しくなります）、ローカルポートは排他的に使うため、PC 上のほかのプログラムが詩音や hook になりすますのを防ぎます
- 同じプロジェクトで Claude Code のセッションを複数開いているときは、各セッションの最初の発言の冒頭数文字をメニューでの区別のためだけにメモリに保持します。ログにもセーブデータにも書かず、終了すると消えます。「状態だけ表示（内容は隠す）」がオンのときは、hook はそもそも送りません
- ChatGPT（Codex）の観測も PC 内だけで行い、詩音が Codex を操作することはありません
- セーブデータとログは `%APPDATA%\Shion` にあります

## よくある質問

**詩音が反応しない**
ダブルクリックして接続状態を確認してください。「パスが無効、または設定が不完全」と出たら、アプリの場所を確認して右クリック →「AI 連携」→「Claude Code」→「接続 / 設定を確認」で再接続してください。そのあと**新しい** Claude Code セッションを開いてください。

**Codex を使うとき、詩音が自動で起動しない**
Claude Code は新しいセッションを開くと詩音を起動してくれますが、Codex ではしません。Codex を使う場合は、右クリック →「設定」→「スタートアップで起動」をオンにしておくと、パソコンを起動したときから詩音がいます。

**ChatGPT（Codex）が作業を始めたのに詩音が反応しない**
Codex デスクトップアプリは「作業開始」のイベントを送らないため、最初にツールを呼び出してから「作業中」になります。ずっと反応しない場合は、Codex の `/hooks` で詩音の Hook が承認されているか確認し、Codex を再起動してください。

**「ポートが使用中」と出る**
詩音はローカルポート `47613` を使います。詩音を 2 つ同時に起動していないか確認してください。

**ウイルス対策ソフトに検出される**
PyInstaller でパッケージしたアプリはまれに誤検出されます。ソースを確認して自分でビルドする（下記参照）か、フォルダを除外リストに追加してください。

**アンインストール方法**
1. 右クリック →「AI 連携」→「Claude Code」→ **切断して設定を削除**（Claude Code の設定から詩音の hooks を削除します）。ChatGPT 連携を入れた場合は「ChatGPT」でも同じ操作をします
2. 右クリック → 「スタートアップで起動」をオフ（オンにしている場合）
3. 右クリック →「終了」で閉じてから、アプリのフォルダと `%APPDATA%\Shion`（セーブデータとログ）を削除

## 既知の制限

- **予定中の V2.1 体力機能（未実装）**：利用枠データを取得できたのは Claude Code のターミナルでの調査のみです。デスクトップ版 Code の既存・新規セッションでは statusLine の記録がなく、hook による代替手段も未検証です。
- ChatGPT（Codex）は観測のみです。許可・停止・中断はできず、「作業リモコン」は Claude Code にだけ効きます
- Codex デスクトップアプリは「開始」イベントを送らないため、最初のツール呼び出しまで「作業中」になりません
- Codex は詩音を自動で起動しません（上のよくある質問を参照。「スタートアップで起動」をおすすめします）
- Codex デスクトップアプリでの実機検証はまだ限られており、状態がずれることがあります

## ソースから実行

```bat
git clone https://github.com/iLLyaaaaaa/shion.git
cd shion
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
start.bat
```

Python 3.10 以上が必要です。スプライト画像は処理済みです。`tools/process_sprites.py` は非公開の元画像が必要なため、通常のユーザーは実行する必要はありません。ビルド：`.venv\Scripts\python tools\build.py`（出力先 `dist\Shion\`）。テスト：`.venv\Scripts\python -m pytest -q`。
