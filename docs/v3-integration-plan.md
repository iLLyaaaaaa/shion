# V3 接入开发预览方案

状态：2026-11-08 接入前方案，尚未实施正式程序改动。

## 目标与基线

将当前 V3 骨架立绘接入正式诗音的窗口、状态和功能，提供可切回旧版的源码试用入口。首版不替换默认立绘，不修改已安装程序、真实连接配置或自启动，不 push。

- V3 工作树：`feature/v3-rig`，已提交基线 `4a7e9a5`；挠痒、脸颊专用拎起和缓存优化仍未提交。
- 正式功能已提交基线：`feature/v2.2-chat-mcp` 的 `45d87b3`，包含桌面聊天联动及 Claude Code 控制隔离。
- 主目录目前另有未提交的窗口、状态、台词和交互修改，不能覆盖或未经确认纳入接入成果。

先把当前 V3 原型保存为明确标注待验收项的本地检查点，再从最新正式已提交基线建立独立 `codex/v3-integration` 工作树并引入 V3 成果。处理两条分支共有文件的冲突时保留最新聊天联动，不在主目录切分支、还原、暂存或提交。主目录未提交修改暂留原处；其完成后再明确对齐。

## 首版范围

1. 源码入口增加 `--renderer v3`，默认继续使用旧版；快照入口支持相同选择。第一阶段不写入存档作为默认选择。
2. 在 `shion/` 增加 V3 显示适配层，复用现有 `v3proto` 的骨架、材质、动画和反应代码，不复制两份渲染器；独立预览入口继续可用。此阶段不进行大的模块搬迁。
3. 正式状态机负责工作、好感、统计、台词与固定表情，V3 负责当前画面和暂时的交互动作。动作结束读取当前底层状态，避免恢复成已经过期的工作或待机状态。
4. 接入透明窗口、可见轮廓命中、透明处点穿、气泡、右键菜单、尺寸设置，以及授权/输入/检查点等现有面板。保留原有窗口置顶和不抢焦点行为。
5. 接入已确认的敲头、摸头、捏脸、肚子揉动和脸颊拎起；实际交互按正式功能规则调用奖励/台词/统计。仅悬停不触发交互计时。周报领取等既有优先点击先消费，避免新手势抢占。
6. V3 仅从左侧突出的脸颊向上提开始拎起；横向拉继续捏脸。持有期间保持脸颊拉伸，松手后才弹回；松手回原站位沿用当前已确认规则，跨屏与工作区边界另做验证。旧版模式的行为保留。

## 首版表情映射草案

正式状态名称和业务语义保持，显示映射单独管理。

| 正式状态 | V3 首版显示 |
|---|---|
| idle | neutral；得意可由用户手动选择 |
| working | neutral，保留工作气泡和状态提示 |
| happy / done / cheer | happy |
| proud | smug |
| stop | angry，缺少挡手姿势暂用表情表达 |
| dizzy | dizzy |
| neglect2 | teary |
| sleep / bed / desk | sleep，首版保留站姿，不声称已有床睡/趴桌素材 |

缺少的道具和特殊姿势先使用已存在的 V3 表情回退，业务功能照常处理，操作说明列明视觉缺口；不在本阶段新造图片。固定表情依同一映射适配，交互结束恢复当前固定/自动状态。

## 性能与验收

- 当前机器已核实 DPR=1.5；用户真实窗口截图约 30.4 FPS，P95 绘制 29.2ms。DPR=1 离屏的 60.20 FPS 不作为此环境验收依据。
- 按实际显示高度 160/200/260/320、DPR=1/1.5 测普通动画和持续交互，记录实际绘制 FPS、P50/P95、渲染设备尺寸。性能问题与试用入口并行推进，不降低纹理分辨率来悄悄换取帧率。
- 核对透明点穿、边缘点击、缩放后命中、原表情恢复、脸颊持有/释放、跨屏失焦，以及工作事件到来时动作与面板的优先级。
- 验证聊天联动和 Claude Code 控制边界保持；用隔离/合成事件完成自动验证，真实客户端验证独立记录，不修改用户连接配置。
- 运行新增适配测试、V3 回归和全仓测试。原有 16 项断言基线失败及全仓汇总后原生退出异常分别记录，不能笼统宣称全量通过；确认新增失败是否由接入引起。

## 阶段与退出条件

1. 原型检查点：保存已有成果，保留未确认的真实手感、高 DPI/FPS 和全仓退出问题。
2. 可切换接入：完成独立工作树、可选渲染器、状态映射、透明窗口与基础交互，生成正式程序 V3 快照。
3. 功能与性能验收：补气泡/菜单/面板联动与真实 DPI 验证，用户体验通过后按仓库规则本地提交。
4. 默认替换与打包发布另议，本方案不自动升级为默认替换、安装或 push 授权。

允许正式程序代码修改的范围为独立接入工作树中的显示适配、必要入口/窗口/状态接线、测试、文档及必要的资源打包声明。现有聊天协议、权限控制语义、真实配置与主目录未提交文件不在本阶段修改范围。
